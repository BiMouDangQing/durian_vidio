## 一、简介

工具读取一段「音频数字信号」（采样点序列），计算其短时傅里叶变换（STFT），并导出两张谱图：

1. **频谱图（STFT）**：幅度谱（dB），频率轴为线性 Hz 刻度。
2. **梅尔频谱（Mel）**：将频率映射到梅尔刻度（更贴近人耳感知），默认 128 个梅尔频带。

---

## 二、快速开始

```powershell
# 单个 CSV 文件（默认采样率 22050）
D:\anaconda\envs\vidio_data\python.exe tools\spectrogram.py D:\data\signal.csv --out_dir D:\结果目录 --kind both

# 批量处理多个文件
D:\anaconda\envs\vidio_data\python.exe tools\spectrogram.py D:\data\a.csv D:\data\b.wav D:\data\c.txt --out_dir D:\结果目录 --kind both --sr 22050
```

运行完成后，打开输出目录查看：

- `{文件名}_stft.png` —— 频谱图
- `{文件名}_mel.png` —— 梅尔频谱
- `preview.png` —— 所有文件的汇总预览图

## 三、支持的输入格式

| 格式 | 说明 |
| :--- | :--- |
| `.csv` / `.txt` / `.dat` / `.tsv` / `.asc` | 纯数值文本，采样率需用 `--sr` 指定（默认 22050） |
| `.npy` | NumPy 数组（取第一个数组） |
| `.npz` | NumPy 压缩数组 |
| `.wav` / `.flac` / `.mp3` 等 | 音频文件，自动读取文件自带采样率 |

**文本/数组列的选择规则（自动识别）**：

- 单列 → 直接作为信号；
- 两列且第一列单调递增（常见 `[索引/时间, 幅度]` 格式）→ 取第二列；
- 其余多列情况 → 默认取第一列，可用 `--column N` 指定第 N 列。

---

## 四、两个转换功能

| 参数值 | 功能 | 频率轴 |
| :--- | :--- | :--- |
| `--kind stft` | 频谱图（STFT 幅度谱） | 线性 Hz |
| `--kind mel` | 梅尔频谱 | Mel 刻度 |
| `--kind both` | 两者都生成（默认） | — |

---

## 五、命令行参数

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `inputs` | 必填 | 输入文件路径，可多个 |
| `--out_dir` | `./spectrogram_out` | 输出目录 |
| `--kind` | `both` | 转换类型：`stft` / `mel` / `both` |
| `--sr` | `22050` | 文本/数组数据的采样率（音频文件自动忽略） |
| `--n_fft` | `2048` | FFT 窗口大小 |
| `--hop_length` | `512` | 帧移 |
| `--n_mels` | `128` | 梅尔频带数 |
| `--cols` | `4` | 预览图每行列数 |
| `--delimiter` | 自动识别 | 文本分隔符，如 `,` 或 `\t` |
| `--skip_header` | `0` | 跳过的表头行数 |
| `--column` | 自动识别 | 取第几列作为信号（从 0 开始） |

## 六、输出文件说明

| 文件 | 说明 |
| :--- | :--- |
| `{文件名}_stft.png` | STFT 频谱图（横轴时间，纵轴 Hz，颜色 dB） |
| `{文件名}_mel.png` | 梅尔频谱图（横轴时间，纵轴 Mel） |
| `preview.png` | 批量汇总预览图 |

## 七、批量预览

批量处理完成后，工具自动把每个文件生成的谱图拼成一张网格预览图 `preview.png`：

- 每格标题为源文件名；
- 行数/列数由文件数量与 `--cols` 决定。

在前端界面中还可通过「上一张 / 下一张」逐张浏览每个文件的输出图。

---

## 八、前端界面使用

1. 先安装 Qt 绑定（二者其一）：

   ```powershell
   pip install PySide6
   ```

2. 启动前端：

   ```powershell
   D:\anaconda\envs\vidio_data\python.exe qt\frontend.py
   ```

3. 切换到「频谱图转换」页签：
   - 「添加文件…」选择单个或多个输入文件；
   - 「添加目录…」递归扫描目录内所有支持格式；
   - 设置采样率、转换类型、输出目录；
   - 点击「开始转换」；
   - 完成后下方自动显示汇总预览图，可用「上一张 / 下一张」浏览。

## 九、常见问题

### 1. 提示 `list index out of range` / 谱图空白

通常是输入文件为空或格式不匹配。检查 CSV 是否为纯数值、是否有多余表头（可用 `--skip_header 1` 跳过）。

### 2. 预览图中文标题显示为方框

首次运行后若中文字体仍不生效，确认系统已安装「微软雅黑 / 黑体」，或改用英文文件名。工具已默认配置中文字体。

### 3. 前端报 `未找到 PySide6 或 PyQt5`

按第八章第 1 步安装 Qt 绑定后重试。

### 4. 音频文件与 CSV 混批处理时采样率不一致

音频文件使用文件自带采样率，CSV 使用 `--sr` 指定值；两者互不影响，可放心混批。
