## 三、从零搭建步骤（新机器 / 新同事）

```powershell
# 1. 创建 Python 3.11 环境
conda create -n vidio_data python=3.11 -y

# 2. 激活环境
conda activate vidio_data

# 3. 安装依赖（在项目目录下）
cd D:\model\model\vidio
pip install -r requirements.txt

# 4. 验证安装
python -c "import numpy, scipy, sklearn, librosa, soundfile, matplotlib, joblib; print('ok')"
```


## 七、常见问题（FAQ）

### 1. 升级 Python 大版本后，import 报 `ModuleNotFoundError`

**原因**：旧版本编译的 `.pyd`/`.dll`（如 `cp38` wheel）在新 Python 下无法加载；而 `pip` 会因为“Requirement already satisfied”**不会自动重装**这些包。

**解决**：强制重装编译型依赖：

```powershell
pip install --upgrade numpy scipy scikit-learn numba librosa soundfile matplotlib joblib tqdm
pip install --upgrade --force-reinstall cffi soxr msgpack contourpy kiwisolver fonttools pillow
```

### 2. `numba` 装不上 / 提示版本不支持

`numba` 对 Python 版本有严格上限。升级 Python 后重新 `pip install --upgrade numba` 即可；若 Python 太旧（如 3.8），最高只能用 `numba 0.58.1`。

### 3. `soundfile` 报 `No module named '_cffi_backend'`

`cffi` 的二进制包损坏（常见于跨 Python 版本升级后）。执行：

```powershell
pip install --upgrade --force-reinstall cffi
```

### 4. 想换回 base 环境

```powershell
D:\anaconda\python.exe audio_cleaner.py --input_dir ...
```

（base 环境为 Python 3.13.5，依赖同样已安装。）

## 八、环境隔离建议

- 清洗任务与训练任务尽量用独立 conda 环境，避免依赖互相污染。
- 升级 Python 前，先记录当前环境：`conda list --explicit > env_snapshot.txt`。
- 变更后务必跑一次冒烟测试（见使用手册「快速验证」章节）。
